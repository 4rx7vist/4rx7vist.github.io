# Portfolio surface

Mode: Experience. Scope: homepage plus static system case studies.

Visitors evaluate an engineer's work and decide whether to discuss a system. The opening connects a personal statement to the Build ↔ System interaction. One action changes engineering components into a readable request flow. This is explicitly an illustrative architecture, not a deployed system claim.

Progression: personal hero, media-led Selected Systems, compact system index, introduction and purpose-grouped tools, honest Lab directions, two-column project intake. Every case study is generated from the same typed data as its listing.

User-pinned constraints: static Astro and pnpm; no new framework; white background; Nata Sans; SVG morph and reduced-motion alternative; no loading hidden 3D assets; no fake outcomes, artificial portrait, or fake form delivery.

Pending editorial input: portrait, project role/year/status/constraints/results/lessons, and actual Lab entries. Until verified, these are labeled TODO. Contact uses an email draft until an HTTPS provider endpoint is configured.
